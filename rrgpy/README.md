# 板块 RRG + 扩散度分析系统

基于东财行业板块数据的 Streamlit Web 应用，通过 RRG（相对旋转图）和市值加权扩散度分析 A 股板块轮动。

## 安装

```bash
pip install -r requirements.txt
```

## 启动

```bash
cd rrgpy
streamlit run app.py
```

浏览器访问 http://localhost:8501

## 使用说明

1. 侧边栏选择要分析的行业板块（可通过快捷筛选或搜索）
2. 点击「🔄 刷新数据」拉取最新数据
3. 左侧 RRG 图看板块相对位置和运动方向
4. 右侧扩散度图看板块内部成分股健康状况
5. 下方表格可排序、多选

## 参数说明

- **窗口**: RS-Ratio / RS-Momentum 的滚动窗口（日）
- **尾巴**: RRG 图中每个板块的轨迹点数量
- **回看期**: 数据回看天数
- **扩散度 MA**: 扩散度移动平均周期

## 数据来源

全部数据来自东方财富 push2 API，零第三方数据依赖。
